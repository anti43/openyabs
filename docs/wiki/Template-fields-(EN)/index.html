    All Template Fields (Complete Reference)¶

    Deutsch: Alle Vorlagenfelder (DE) · Back to Templates (EN)

    This page lists all built-in placeholders populated by YaBS when generating documents (ODT/PDF).

    • Syntax in ODT templates (LibreOffice): angle brackets, e.g. <item.cnumber> or <companyinfo.vatid>.
    • Syntax in email templates and text variables: square brackets, e.g. [item.cnumber] or [contact.fullname].
    • Empty values: If a field has no value, it renders empty (no raw placeholder text in the PDF).
    • Live inspector inside YaBS: Under Control Panel › Templates › Show all placeholders, YaBS lists every available field with its live value for a real document (double-click copies the placeholder).

    1. Documents (item.*)¶

    Applies to Invoice (0), Order (1), Offer (2), Delivery Note (3), Order Confirmation (4), Contract (11), Serial Mail (13), Credit Note (20), Part Payment Invoice (21), and Deposit Invoice (22).

    General document fields¶

    Field Description
    item.cnumber Document number (e.g. INV-2026-0001)
    item.cname Short title / subject of the document
    item.description Free-text description / notes (variables are evaluated)
    item.type Document type label (e.g. Invoice, Offer, Credit note)
    item.status Status label (e.g. Finished, Paid, Cancelled)
    item.dateadded Issue / document date
    item.servicedate Delivery / service date (BT-72; falls back to issue date in e-invoices)
    item.dateend Payment date or end date
    item.datetodo Due / follow-up date
    item.datelastupdated Last modified date (set automatically)
    item.reference Referenced source document (e.g. order number)
    item.account Accounting account of the document
    item.group Group name
    item.grouppath Full group hierarchy path
    item.groupdescription Group description
    item.addedby Username of the creator
    item.addedbyfull Full name of the creator

    Amounts, discounts & payments¶

    Fields without f are plain numbers (e.g. 1,226.30); fields ending in f include the local currency symbol (e.g. 1.226,30 €).

    Field Description
    item.netvalue / item.netvaluef Net total after discount
    item.netnodiscvalue / item.netnodiscvaluef Net total before discount (list price)
    item.taxvalue / item.taxvaluef Total VAT / tax amount
    item.grosvalue / item.grosvaluef Gross total / invoice amount after discount
    item.grosnodiscvalue / item.grosnodiscvaluef Gross total before discount
    item.discountvalue / item.discountvaluef Total net discount
    item.discounttax / item.discounttaxf Tax portion of the discount
    item.discountgrosvaluef Total gross discount (formatted)
    item.paidvaluef Partial payments already received (empty if none)
    item.openvaluef Remaining open amount (empty if no payments recorded)

    Payment terms, bank account & cash discount (Skonto)¶

    Field Description
    item.paymentdays Payment term in days (0 = payable immediately)
    item.paymentduedate Calculated due date
    item.paymentterms Ready-to-print payment term text (e.g. "Payable until 29.11.2026" or "Payable immediately without deduction")
    item.paymentiban Target bank IBAN (customer's assigned account or company default)
    item.paymentbic Target bank BIC
    item.paymentbank Target bank name
    item.paymentaccountname Target account label
    item.skontopercent Cash discount (Skonto) percentage (empty if none)
    item.skontodays Skonto period in days
    item.skontodate Skonto cutoff date (issue date + Skonto days)
    item.skontoamount Skonto discount amount (on gross)
    item.skontopayamount Payable amount after deducting Skonto

    VAT breakdown per tax rate (§ 14 Abs. 4 Nr. 8 UStG)¶

    For a dynamic table with one row per tax rate (highest rate first), use vatgroups.* inside a table row:

    Field Description
    vatgroups.name Tax rate name (e.g. VAT 19.00 % or Tax free)
    vatgroups.rate Formatted tax rate (e.g. 19.00 %)
    vatgroups.ratevalue Numeric tax rate (e.g. 19, 7, 0)
    vatgroups.net / vatgroups.netf Net total for this rate
    vatgroups.vat / vatgroups.vatf Tax amount for this rate
    vatgroups.gross / vatgroups.grossf Gross total for this rate
    vatgroups.category EN 16931 VAT category code (S, E, K, AE, G)
    vatgroups.note Tax exemption / legal note for this rate

    Additional fixed fields directly on the document:

    Field Description
    item.vatgroup1.* … item.vatgroup3.* Same subfields (name, rate, ratevalue, net, netf, vat, vatf, gross, grossf, category, note) for fixed layouts
    item.vatgroupcount Number of distinct tax rates in the document
    item.hasmultipletaxrates true if more than one tax rate is used, else false
    item.taxnotes Combined legal VAT notes (reverse charge, intra-EU supply, export, small business)
    item.tax Tax rate (legacy templates; lowest rate if multiple)
    item.taxgroup1, item.taxgroupvalue1 … Legacy per-rate fields
    item.taxgroups All tax rates as text (legacy templates)

    Credit notes / corrections & final invoices¶

    Field Description
    item.correctedinvoice Formatted reference to the corrected invoice (e.g. "Invoice INV-2026-0001 of 04.11.2026")
    item.correctedinvoicenumber Number of the corrected invoice
    item.correctedinvoicedate Date of the corrected invoice
    item.finalinvoice true when deposit / part-payment invoices are deducted
    item.deductedinvoices Summary list of deducted deposit / part-payment invoices
    item.deductednetf Sum of deducted net amounts (formatted)
    item.deductedtaxf Sum of deducted tax amounts (formatted)

    Cross-border trade & customs (export / commercial invoice)¶

    Field Description
    item.currency ISO 4217 currency code (BT-5, e.g. EUR, CHF, USD)
    item.incoterms Incoterms® + named place (e.g. DAP Zürich), from invoice or contact property incoterms
    item.netweight Total net weight (kg); automatically summed from linked product weights if invoice property netweight is not set
    item.grossweight Total gross weight (kg), from invoice property grossweight
    item.packages Package count / description, from invoice property packages

    2. Position Table (xtable1)¶

    In ODT templates, name the positions table xtable1. Choose and order its columns in the Template Manager via Choose columns … (format string, e.g. 1,2,4,5,7,6):

    Column Content
    1 Position number (Count)
    2 Quantity
    3 Unit (Measure, e.g. pcs, hrs)
    4 Description
    5 Unit price net
    6 Total net (before discount)
    7 VAT rate (%)
    8 VAT amount
    9 Total gross
    10 Position link / URL
    11 Short name (Cname)
    12 Discount (%)
    13 Total net after discount
    14 HS / CN customs tariff code of the linked product
    15 Country of origin (ISO 3166 alpha-2) of the linked product
    16 Line net weight in kg (unit weight × quantity)

    Note: When global setting org.openyabs.exportproperty.productsresolved is enabled, all fields of the linked product are appended alphabetically starting at column 17.

    3. Contact (contact.* / item.contact.*) & Addresses¶

    Use prefix contact.* in contact sheets, item.contact.* in documents, productorder.contact.* in supplier orders, and conversation.contact.* in conversation notes.

    Field (without prefix) Description
    cnumber Customer / supplier number
    title Title (e.g. Dr.)
    prename First name
    cname Last name (or company name for company-only contacts)
    fullname First name + last name
    company Company name
    department Department
    gender Salutation (Mr. / Ms.)
    intro Letter greeting (e.g. Dear Mr. / Dear Ms.)
    street Street and house number
    zip Postal code
    city City
    country Full country name
    mainphone Main phone number
    workphone Work phone
    mobilephone Mobile phone
    fax Fax number
    mailaddress Email address
    website Website
    taxnumber Buyer VAT ID (USt-IdNr.)
    eori Buyer EORI number (property eori)
    peppolid Buyer Peppol-ID (BT-49, property peppol-id)
    bankaccount IBAN / account number
    bankid BIC / bank code
    bankname Bank name
    bankcountry Bank country
    bankcurrency Contact currency (ISO 4217, e.g. EUR, CHF)
    payterm Customer payment term (days)
    taxrate Default VAT rate of the contact (%)
    taxname Name of the default VAT rate
    notes Notes
    dateadded Creation date

    Additional addresses¶

    Additional addresses of a contact are exposed as sub-objects with the same address fields (title, prename, cname, fullname, company, department, gender, intro, street, zip, city, country, taxnumber):

    Sub-object Description
    …contact.invoiceaddress.* (alias …contact.invoice.*) Billing address (falls back to main address)
    …contact.deliveryaddress.* (alias …contact.delivery.*) Delivery / ship-to address (e.g. <item.contact.deliveryaddress.street>)
    …contact.address.* Default address
    …contact.address0.*, …address1.* … Additional addresses by index

    5. Products & Services (product.*)¶

    Applies to Product Sheet (5) and Service Description (6):

    Field Description
    product.cnumber Product / service number
    product.cname Name
    product.description Description
    product.type Type (Product or Service)
    product.measure Unit (e.g. pcs, hrs)
    product.externalnetvalue Sales price net
    product.externalbrutvalue Sales price gross
    product.internalnetvalue Purchase price net
    product.tax / product.taxpercentvalue VAT rate (%)
    product.ean EAN / GTIN
    product.reference Manufacturer / reference code
    product.url Web link
    product.stockvalue Current stock quantity
    product.thresholdvalue Minimum stock threshold
    product.hscode HS / CN customs tariff code (BT-158)
    product.origincountry Country of origin (BT-159, ISO 3166 alpha-2)
    product.netweight Net weight per unit in kg
    product.productgroup.cname Product group name
    product.supplier.* All contact fields of the default supplier
    product.manufacturer.* All contact fields of the manufacturer

    6. Reminders (reminder.*), Supplier Orders (productorder.*) & Conversations (conversation.*)¶

    Prefix / Field Description
    reminder.cnumber, reminder.dateadded, reminder.description Reminder number, date, text
    reminder.extravalue Reminder fee
    reminder.stage.cname Dunning stage name (e.g. 1st Reminder)
    reminder.item.* All document & contact fields of the overdue invoice (e.g. reminder.item.cnumber, reminder.item.grosvaluef, reminder.item.paymentduedate, reminder.item.contact.fullname)
    productorder.* Supplier order: cnumber, cname, description, status, dateadded, dateend, datetodo, netvalue(f), taxvalue(f), grosvalue(f), discountvalue(f), productorder.contact.*, table productorder.xtable1
    conversation.* Conversation note: cnumber, cname, description, dateadded, conversation.contact.*

    7. Journal (journal.*)¶

    Applies to the Journal template (9) (table Journal.xtable1 contains all visible journal rows):

    Field Description
    journal.datefrom / journal.dateto / journal.datenow Period start / end / current print date
    journal.group / journal.childgroups Selected groups / include subgroups (true/false)
    journal.user / journal.accounts User filter / account filter
    journal.netvalue / journal.taxvalue / journal.grosvalue Document volume net / tax / gross
    journal.revenuevalue / journal.revenuetax / journal.revenuegrosvalue Income net / output VAT / gross
    journal.expensevalue / journal.expensetax / journal.expensegrosvalue Expenses net / input VAT / gross
    journal.profitvalue / journal.profittax / journal.profitgrosvalue Surplus net / VAT balance / surplus gross
    journal.discountvalue Total discounts
    journal.openreceivables / journal.openpayables Open receivables / open payables
    journal.openoffers / journal.openorders Open offers / open orders

    8. Cash Register & TSE (pos.*)¶

    Available on receipts of the built-in POS cash register (Cash register and TSE):

    Field Description
    pos.time Time of sale (HH:mm)
    pos.seller Cashier / seller name
    pos.storno Cancellation marker on cancelled receipts
    pos.register.serial Cash register client ID / serial
    pos.tse.note / pos.tse.failed TSE notice / failure indicator
    pos.tse.transaction / pos.tse.counter TSE transaction number / signature counter
    pos.tse.start / pos.tse.end Transaction start and end timestamp
    pos.tse.serial / pos.tse.algorithm TSE serial number / signature algorithm
    pos.tse.signature / pos.tse.processdata Signature value / process data
    pos.tse.qrdata TSE QR code payload (automatically rendered for TSEQRCode.img)

    9. Image Placeholders (QR Code & Barcode)¶

    Set the image name in LibreOffice Writer under Image › Properties › Options › Name:

    Image name Description
    QRCode.img EPC QR code (GiroCode) for bank transfers on invoices (QR code)
    Barcode.img (or Code39.img) Code 39 barcode of the document/record number (cnumber) with human-readable text below
    TSEQRCode.img TSE QR code on POS receipts (Cash register and TSE)

    10. Custom Fields (Properties & Scripts) and Plugins¶

    • Custom fields: Any property NAME defined on a record or in the Script Manager is available as <item.property.NAME>, <contact.property.NAME>, <item.contact.property.NAME>, or <product.property.NAME> – see Templates and Scripts.
    • Official plugins provide their own placeholders when enabled:
    • Skilled Trades plugin (hw.* – construction site, § 35a EStG, § 13b/§ 48b, retention)
    • Heilpraktiker plugin (hp.* – diagnosis, ICD-10, treatment dates, § 4 Nr. 14 UStG)
    • Association plugin (verein.* – member data, 4 tax spheres, donation receipt)
    • Car Repair Shop plugin (ws.* – vehicle, plate, VIN, mileage, inspection due)
